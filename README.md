# Eddie@Bangmod

Play as Eddie, a KMUTT Bangmod student with 90 seconds to fill shopping lists in a street market. Dodge motorbikes and soi dogs, then post your score to the leaderboard.

![Market Sprint cinematic showing Eddie running through the market at dusk](packages/studio/artwork/market-sprint.png)

## Getting Started

Run from the repository root with Bun:

```bash
bun install
bun run dev
```

Open [http://localhost:3001](http://localhost:3001).
